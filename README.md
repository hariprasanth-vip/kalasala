## 🚀 Projects

### 🧠 [AdaptIQ](./adaptiq)
**AdaptIQ** is an Adaptive Pedagogy & AI Tutoring Engine that learns from its student in real time.
- **Frontend**: Modern Dark Cyber-Glass Cockpit with Live AI Learning Monitor (`adaptiq/client`)
- **Backend**: Node.js, Express, MongoDB, and Multi-Model AI Orchestration (Gemma 3 via Ollama, Google Gemini 2.5, Groq fallback) (`adaptiq/server`)

For full details, setup instructions, and demo walkthrough, please see the [AdaptIQ README](./adaptiq/README.md).
